Jar Workbench

Open a .jar, browse its contents, decompile its classes to Java, edit the source, and recompile it back into class files. Runs entirely in this tab, nothing gets uploaded.

Decompiling and recompiling runs a real JVM (CheerpJ) plus the CFR decompiler, both loaded on demand, so the first run is slow to warm up. Decompiled code doesn't always recompile clean. Lambdas, inner classes and enums sometimes need a manual fix, check the console panel for compiler errors.
